# OpenAtmos

> 把分散的气象知识，整理成一条可学习、可验证、可实践的开放路径。

OpenAtmos 是一个面向气象学初学者和应用气象学本科生的中文知识平台。项目用自己的文字解释核心概念，同时通过链接连接优秀的课程、数据和开源工具。

## 为什么做 OpenAtmos

气象学的知识分布在教材、课程讲义、数据文档和开源项目中。资源并不缺，缺少的是一张能回答下面问题的地图：

- 这个概念解决什么问题？
- 它和前置知识、天气现象有什么关系？
- 应该用什么观测或数据来理解它？
- 学完之后能做一个什么小实践？

OpenAtmos 试着把这些连接补上。

## 适合谁

- 想从零建立气象学框架的学习者；
- 应用气象学、气象学、地理科学及相关专业本科生；
- 想从天气现象进入大气科学的读者；
- 想学习气象数据处理，但不希望只从代码库 README 开始的人。

## 学习路线

| 阶段 | 主题 | 学习结果 |
| --- | --- | --- |
| 01 | 气象学基础 | 分清天气、气候、大气状态和气象要素 |
| 02 | 大气热力学 | 理解温度、水汽、稳定度和云降水的基本联系 |
| 03 | 大气动力学与天气系统 | 从气压场、风场和尺度理解天气变化 |
| 04 | 观测与资料 | 认识地面观测、探空、雷达、卫星、再分析和预报资料 |
| 05 | 应用气象 | 将气象信息连接到农业、城市、生态、健康、交通和能源问题 |
| 06 | Python 与气象数据 | 用可复现的小练习读取、分析和可视化气象数据 |

当前首期内容从[01 气象学基础](courses/01-气象学基础/README.md)开始，第一课是[天气、气候与大气科学](courses/01-气象学基础/lessons/01-天气-气候-应用气象.md)。

## 每个知识单元会回答什么

1. 学完之后应该会什么；
2. 需要哪些前置概念；
3. 概念如何用直观语言和必要公式解释；
4. 它对应什么天气现象或实际问题；
5. 如何用观测资料或简单练习验证；
6. 哪些地方最容易混淆；
7. 可以继续阅读哪些高质量外部资源。

## 外部项目与资料

OpenAtmos 不复制优秀项目的全部内容。它会保留项目链接、许可证和适用说明，再用自己的文字解释这些资源适合放在学习路径的哪一段。

首期优先连接：

- [MetPy](https://github.com/Unidata/MetPy)：读取、可视化和计算气象数据的 Python 工具；
- [ECMWF training](https://github.com/stewartchrisecmwf/training)：气候与大气资料的 Jupyter Notebook 教程；
- [NMC-WFT/nmcdev](https://github.com/nmcdev)：中国气象业务数据、绘图、雷达和预报检验相关工具；
- [NOAA weather vs. climate](https://www.ncei.noaa.gov/news/weather-vs-climate)：天气与气候概念的官方科普解释。

更多选择和引用规范见[首期文案与内容路线](docs/content-roadmap.md)。

## 参与方式

欢迎通过 Issue、Pull Request 或讨论提出：

- 概念表述的错误或歧义；
- 缺少的先修知识和练习；
- 适合补充的公开课程、数据和工具；
- 南京、江苏及其他地区的天气案例。

贡献内容请尽量附上来源、许可证和适用范围。平台优先接受可核查、可复现、能帮助学习者建立联系的内容。

## 项目状态

当前处于内容体系搭建阶段。首期目标不是一次写完所有气象学，而是先验证“一个知识单元能否形成完整学习闭环”，再逐步扩展。
