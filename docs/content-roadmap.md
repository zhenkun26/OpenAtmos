# OpenAtmos 首期文案与内容路线

## 1. 定位文案

### 一句话定位

OpenAtmos 是面向中文初学者和应用气象学本科生的开放气象知识平台：用自己的文字解释核心知识，用外部链接连接课程、数据和工具，用小练习把概念落到天气现象和真实资料上。

### 对外主张

> 从一个天气现象出发，理解背后的大气过程，找到可以继续学习和动手验证的路径。

### 不承诺什么

- 不承诺替代教材、课堂或专业预报服务；
- 不承诺收集所有气象资料；
- 不把未经核验的个人笔记包装成权威结论；
- 不直接镜像未明确授权的教材、课件、图片或数据。

## 2. 写作语气

| 维度 | 约定 |
| --- | --- |
| 清楚 | 先给结论和直观图景，再补充术语、公式与限定条件 |
| 严谨 | 事实、解释、推测和练习题分开表达 |
| 具体 | 尽量交代时间、地点、尺度、单位和资料来源 |
| 克制 | 不用“神奇”“一招看懂”等会制造错误期待的表达 |
| 可继续 | 每篇内容都给出下一步学习入口，而不是在文末堆一串链接 |

## 3. 内容架构

### 主线路

1. 气象学基础：天气、气候、大气组成、气象要素和尺度；
2. 大气热力学：温度、水汽、饱和、抬升、稳定度和云降水；
3. 大气动力学与天气系统：气压梯度、风、旋转、辐合辐散和天气尺度；
4. 观测与资料：地面观测、探空、雷达、卫星、再分析和数值预报；
5. 应用气象：农业、城市、生态、健康、交通和能源；
6. Python 与气象数据：变量、文件、绘图、诊断和可复现分析。

### 首期切片

首期只实现一条最小闭环：

```text
平台定位
  → 领域词汇
  → 学习路线
  → 一个入门知识单元
  → 外部资源入口
  → 贡献与反馈方式
```

完成标准是：一个第一次访问仓库的读者，能在几分钟内知道项目服务谁、从哪里开始、每篇内容大致怎么学，以及如何继续使用外部资源。

## 4. 知识单元模板

后续文章默认按以下顺序组织：

```markdown
# 标题

> 一句话说明本单元要解决的问题。

## 学习目标
## 前置知识
## 先从现象开始
## 核心概念
## 公式、单位与适用条件
## 观测或数据练习
## 常见混淆
## 小结
## 继续阅读
```

不是每篇都需要复杂公式，但每篇都要有学习目标、一个可感知的现象或问题、一个小结和下一步入口。

## 5. 外部资源引用规范

外部项目作为“可访问的工具或课程”出现，至少记录：

- 项目名称和原始链接；
- 它解决什么问题；
- 适合哪一阶段的学习者；
- 许可证或使用限制；
- OpenAtmos 为什么推荐它；
- 访问或核验日期。

链接是入口，不是内容替代。OpenAtmos 只在许可证允许或明确取得授权时复用代码、图片、数据和文字；否则以自己的解释、原始链接和必要引用为主。
