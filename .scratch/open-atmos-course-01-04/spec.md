# OpenAtmos 课程 01：温度、气压与风的初步联系

Status: archived

## 目标

完成课程 01 的第四个知识单元，让学习者能够从简单气压场示意图中识别高低压、等压线疏密和压力梯度，并理解它们与风速、风向之间的初步联系。

## 范围

- 一篇面向初学者的短课；
- 一张原创气压场与风关系 SVG 图；
- 一个气压场读图练习，包含问题、解答和讲解；
- 更新课程入口、资源与任务归档；
- 提交并推送到已确认的 `origin/main`。

## 不在范围内

- 地转风、梯度风和热成风公式；
- 完整的天气系统、锋面和气旋结构分析；
- 用简化图推导真实城市或台风风场；
- 真实气象数据下载、制图脚本或新的 Python 依赖；
- force push、重写远程历史或覆盖他人提交。

## 不变量与验收证据

1. 明确“压力梯度力倾向于把空气从高压推向低压”是入门模型，真实近地面风还受地球自转、摩擦、地形等因素影响。
2. 明确等压线越密表示单位距离内气压变化越快，通常对应更强的压力梯度；不把“线密”写成绝对的风速保证。
3. 区分风向的气象学约定：风向通常指风从哪里来，而不是空气流向哪里。
4. 原创 SVG 包含 `title`、`desc` 和 Markdown 替代文字，并标注“教学示意，不是实况天气图”。
5. 课程单元包含现象入口、核心概念、一张图、读图示例、回忆题、常见混淆和下一步入口。
6. 练习目录遵循 `scaffold-exercises` 的 `problem`、`solution`、`explainer` 结构，所有本地目标可解析。
7. 推送前确认远程仓库仍为 `zhenkun26/OpenAtmos`，只推送 `main`，不使用强制覆盖。

## 失败模式与回退

- 把“风从高压吹向低压”当作真实风向定律：在正文、图注和练习中补上地转偏向和摩擦限制；
- 把等压线数值差与线间距混淆：用“单位距离的变化”解释压力梯度；
- 把风向写成空气运动方向：在第一次引入时同时给出“来自哪里”的例子；
- 读图题出现多解：限定为北半球近地面简化情境，并说明示意图边界；
- 结构或链接检查失败：修复后再提交，不把未验证材料推送；
- GitHub 推送失败：保留本地提交，记录错误，不重复创建仓库或强推；
- 需要撤销公开变更时使用新的 `git revert <commit>`，不改写已发布历史。
