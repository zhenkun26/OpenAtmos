# OpenAtmos 课程 01：水汽、云与降水的入门图景

Status: archived

## 目标

完成课程 01 的第五个知识单元，让初学者能够区分水汽、云和降水，并用“水汽来源 → 空气上升/冷却 → 饱和 → 凝结或凝华 → 粒子增长 → 降水”的过程链解释一个简单天气现象。

## 范围

- 一篇面向初学者的短课，控制概念数量和阅读负担；
- 一张原创水汽—云—降水过程 SVG 图；
- 一个基于合成观测记录的过程判读练习，包含问题、解答和讲解；
- 更新课程入口、资源与任务归档；
- 提交并推送到已确认的 `origin/main`。

## 不在范围内

- 云微物理的完整粒子谱、冰晶习性和降水数值模拟；
- 相对湿度、露点、混合比和饱和水汽压的公式推导；
- 用一组简化观测记录断言真实天气系统的因果关系；
- 下载真实观测数据、制作雷达图或新增 Python 依赖；
- force push、重写远程历史或覆盖他人提交。

## 不变量与验收证据

1. 明确水汽是不可直接看见的气态水，云是悬浮在空气中的微小液滴和/或冰粒集合，降水是从云或大气中落向地面的粒子；不把三者写成同义词。
2. 明确空气冷却至饱和是云形成的重要条件，并说明水汽通常在凝结核上凝结或在冰相过程中凝华；不把“相对湿度高”直接写成“必然下雨”。
3. 明确云不等于降水，且降水粒子可能在到达地面前蒸发，形成雨幡（virga）等现象。
4. 原创 SVG 包含 `title`、`desc` 和 Markdown 替代文字，并标注“教学示意，不按比例绘制”。
5. 课程单元包含现象入口、核心概念、一张图、观察例子、回忆题、常见混淆和下一步入口。
6. 练习目录遵循 `scaffold-exercises` 的 `problem`、`solution`、`explainer` 结构；合成记录明确标注为教学数据，所有本地目标可解析。
7. 推送前确认远程仓库仍为 `zhenkun26/OpenAtmos`，只推送 `main`，不使用强制覆盖。

## 失败模式与回退

- 把“看见云”写成“马上会下雨”：在正文、图注和练习中反复区分云与降水，并引入雨幡边界；
- 把“水汽凝结”写成凭空产生水：补充水汽来源以及冷却、饱和条件；
- 把相对湿度百分数当成空气中水的百分数：用一句通俗边界说明，暂不引入公式；
- 练习把合成记录误读成真实预报：在题面和解答中注明“只用于训练过程推理”；
- 结构或链接检查失败：修复后再提交，不把未验证材料推送；
- GitHub 推送失败：保留本地提交，记录错误，不重复创建仓库或强推；
- 需要撤销公开变更时使用新的 `git revert <commit>`，不改写已发布历史。
