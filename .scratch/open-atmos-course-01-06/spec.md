# OpenAtmos 课程 01：时间尺度与空间尺度

Status: archived

## 目标

完成课程 01 的第六个知识单元，让初学者理解同一场天气可以同时包含不同大小、不同持续时间的过程，并能根据问题选择合适的时间间隔、空间范围和观测资料。

## 范围

- 一篇面向初学者的短课，解释时间尺度、空间尺度、分辨率和代表性；
- 一张原创时间—空间尺度示意 SVG 图；
- 一个基于三种资料视角的尺度判读练习，包含问题、解答和讲解；
- 更新课程入口、资源与任务归档；
- 提交并推送到已确认的 `origin/main`。

## 不在范围内

- Rossby 半径、无量纲数、尺度分析方程或完整动力学推导；
- 把微尺度、中尺度、天气尺度和行星尺度当作没有重叠的硬边界；
- 比较具体模式、雷达或卫星产品的业务性能；
- 下载真实观测数据、制作地图脚本或新增 Python 依赖；
- force push、重写远程历史或覆盖他人提交。

## 不变量与验收证据

1. 明确时间尺度回答“一个变化持续多久”，空间尺度回答“影响范围有多大”；两者通常相互联系，但不是同一个概念。
2. 明确小尺度现象可以嵌套在大尺度天气系统中；示例中的尺度范围只作为入门印象，不作绝对分类边界。
3. 明确时间分辨率、空间分辨率、观测范围和代表性不是同义词；一个站点的高频记录不等于它代表整个城市。
4. 原创 SVG 包含 `title`、`desc` 和 Markdown 替代文字，并标注“教学示意，不按比例绘制”。
5. 课程单元包含现象入口、核心概念、一张图、资料选择例子、回忆题、常见混淆和下一步入口。
6. 练习目录遵循 `scaffold-exercises` 的 `problem`、`solution`、`explainer` 结构；资料表明确标注为教学情境，所有本地目标可解析。
7. 推送前确认远程仓库仍为 `zhenkun26/OpenAtmos`，只推送 `main`，不使用强制覆盖。

## 失败模式与回退

- 把尺度标签写成固定数值边界：改为“典型范围/入门印象”，并提醒不同教材和应用会有差异；
- 把“采样频率高”当成“空间细节丰富”：分别解释时间分辨率和空间分辨率；
- 把一个站点观测推广到整座城市：加入代表性、地形和下垫面差异的限制；
- 把大尺度系统和小尺度天气现象写成互斥：用“雷暴嵌套在天气系统中”的示例纠正；
- 练习把资料视角误当作真实数据结论：明确为教学情境，并要求写出还需验证的资料；
- 结构或链接检查失败：修复后再提交，不把未验证材料推送；
- GitHub 推送失败：保留本地提交，记录错误，不重复创建仓库或强推；
- 需要撤销公开变更时使用新的 `git revert <commit>`，不改写已发布历史。
