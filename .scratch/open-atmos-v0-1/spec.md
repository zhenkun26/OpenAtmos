# OpenAtmos v0.1 首期内容切片

Status: archived

## 问题

项目已经完成仓库和 Agent 工作流初始化，但还没有对外说明“为什么做、服务谁、从哪里开始”，也没有一个能代表内容质量的完整知识单元。

## 目标

完成一个最小但完整的内容闭环：项目定位 → 学习路线 → 领域词汇 → 外部资源规则 → 一个原创入门单元 → 反馈入口。

## 交付物

- 项目首页文案；
- OpenAtmos 领域上下文与规范术语；
- 首期文案与内容路线；
- 一份带来源的 GitHub 气象学习资源调研；
- 一篇原创气象学入门单元；
- 本地任务状态与归档记录。

## 验收标准

- 新读者能在 README 中找到项目定位、适用人群和起始内容；
- 首个知识单元具备学习目标、现象入口、概念解释、练习和延伸资源；
- 外部资源均以原始链接呈现，并说明推荐用途；
- 领域词汇不会把天气、气候、观测、再分析和预报混为一谈；
- 本轮任务状态为 `archived`，且归档记录包含变更、验证和后续队列。

## 不在范围内

- 完整网站前端或在线部署；
- 全部本科课程内容；
- 自动天气预报服务；
- 未获授权的教材、课件、图片或数据镜像；
- 远程 GitHub 仓库创建、推送或 Issue 同步。
