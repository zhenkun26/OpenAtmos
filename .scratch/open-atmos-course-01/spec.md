# OpenAtmos 课程 01：推进到“大气组成与垂直结构”

Status: archived

## 目标

在 `courses/01-气象学基础/` 中完成第二个可独立阅读、可回忆和可练习的知识单元，并把本轮成果同步到公开 GitHub 仓库。

## 范围

- 一篇通俗中文课程单元；
- 一张原创 SVG 垂直结构示意图；
- 一个最小练习，要求学习者根据图和文字进行回忆与判读；
- 更新课程入口、资源说明和本地任务记录；
- 创建一次 Git 提交并推送到已确认的 `origin/main`。

## 不在范围内

- 大气静力学、垂直递减率和稳定度公式；
- 臭氧化学、辐射传输和污染物详细机制；
- 复制 UCAR、NOAA 或其他机构的图片、图注和大段原文；
- 强制安装新的 Python 绘图库或建立尚未验证的 `academic-figure` skill；
- 使用 force push、重写远程历史或覆盖其他人的远程提交。

## 不变量与验收证据

1. “78% 氮气、21% 氧气”等数字明确标注为干空气近似，水汽单独说明其时空变化。
2. 对流层、平流层等高度范围使用“约”并提醒对流层顶随纬度和季节变化。
3. 示意图包含 `title`、`desc` 和 Markdown 替代文字，且由 OpenAtmos 自行绘制。
4. 课程单元包含现象入口、核心概念、一个图、一个例子、回忆题、常见混淆和下一步入口。
5. 练习目录遵循 `scaffold-exercises` 的命名与 `readme.md` 约定，所有本地链接可解析。
6. 推送前确认远程仓库为 `zhenkun26/OpenAtmos`，只推送 `main`，不使用强制覆盖。

## 失败模式与回退

- 资料表述过度精确：回退为近似范围，并保留来源和限定条件；
- 图文关系不清：缩减标签和术语，优先保留“高度—温度趋势—天气位置”三项；
- 链接或结构校验失败：修复后再提交，不把未验证文件推送；
- GitHub 推送失败：保留本地提交，记录远端错误，不重复创建仓库或强推；
- 如需撤销本轮公开变更，使用新的 `git revert <commit>`，不改写已发布历史。
