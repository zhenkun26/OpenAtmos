# 01 气象学基础

> 从“今天的天气”出发，建立理解大气、读取观测资料和进入后续课程所需要的共同语言。

本目录是 OpenAtmos 的第一门课程试作。它服务于气象学初学者、应用气象学本科生以及希望把天气现象和气象数据联系起来的学习者。课程不追求一次讲完所有基础知识，而是把每个知识单元控制在一个可以完成、可以回忆、可以继续实践的范围内。

## 学习结果

完成本课程后，学习者应该能够：

- 区分天气、气候、大气科学、气象学和应用气象学；
- 说清楚温度、气压、湿度、风和降水分别描述什么；
- 用“时间—地点—要素—单位—资料来源”完整描述一条气象信息；
- 初步理解观测、再分析资料和预报结果不是同一种数据；
- 从一个天气现象提出可观察、可验证的气象问题。

## 课程顺序

| 编号 | 单元 | 这一单元只解决一个主要问题 |
| --- | --- | --- |
| 01 | [天气、气候与大气科学](lessons/01-天气-气候-应用气象.md) | 我们到底在描述哪一种“大气状态”？ |
| 02 | [大气组成与垂直结构](lessons/02-大气组成与垂直结构.md) | 空气由什么组成，为什么高度会改变大气状态？ |
| 03 | [气象要素与观测](lessons/03-气象要素与观测.md) | 我们如何把“闷热、起风、下雨”变成可记录的量？ |
| 04 | [温度、气压与风的初步联系](lessons/04-温度-气压与风的初步联系.md) | 为什么气压场和风场能帮助我们理解天气变化？ |
| 05 | [水汽、云与降水的入门图景](lessons/05-水汽-云与降水的入门图景.md) | 空气中的水汽怎样走向云和降水？ |
| 06 | [时间尺度与空间尺度](lessons/06-时间尺度与空间尺度.md) | 为什么同一场天气在不同地点、不同时间看起来不一样？ |
| 07 | 从天气现象到资料判读 | 面对一张站点图或时间序列，先看什么、后看什么？ |
| 08 | 基础课程回顾与小练习 | 能否用一套稳定的问题框架解释一个天气案例？ |

后续单元会在前一单元获得反馈后逐步补齐，不把课程目录误认为已经完成的教材。

## 每个知识单元的节奏

每篇内容默认遵循“短、密、可回忆”的节奏：

1. 一个现实问题或天气现象；
2. 3—5 个本篇必须掌握的术语；
3. 一张承担解释任务的图；
4. 一个带来源的例子或小数据任务；
5. 2—3 个不看答案也能尝试的回忆问题；
6. 一个常见混淆和一个下一步入口。

这里的“知识密度适中”不是减少知识，而是限制同一屏同时出现的陌生概念。公式只在它能帮助解释现象时出现，并同时说明符号、单位和适用条件。

## 统一写作模板

```text
现象或问题
  → 学习目标
  → 核心概念与关系图
  → 一个观测/资料例子
  → 常见混淆
  → 回忆练习
  → 小结与下一步
```

文字先讲清“它解决什么问题”，再引入术语；图片不承担装饰任务，而是帮助读者看见时间尺度、空间关系、因果链或变量之间的联系。每张图都应有替代文字，事实性图表还应记录资料来源和处理方式。
