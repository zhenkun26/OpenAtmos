# 参考解答：读懂大气垂直结构

1. 干空气是暂时排除水汽后的气体组成近似；实际湿空气还含有随地点和时间变化的水汽，以及气溶胶等悬浮粒子。
2. 对流层。它紧邻地面，包含日常天气、绝大多数云和水汽，且与地面观测和气象气球资料直接相连。
3. 总体上都随高度升高而降低。气象气球上升时外界气压降低，气球因此膨胀；探空仪也会记录随高度变化的气压、温度、湿度和风。
4. 平流层中的臭氧吸收太阳紫外辐射并转化为热，使温度随高度的趋势与对流层不同。
5. 气球上升后，周围空气柱变短，外界气压降低；气球内气体向外膨胀，所以气球体积增大。关键不是“高空空气更厚”，而是“高空外界压力更低”。

如果你能在不看课文的情况下解释第 3、4、5 题，说明已经抓住了本课的主线：高度改变会同时影响压力、密度和温度结构，但它们不是同一条变化曲线。
