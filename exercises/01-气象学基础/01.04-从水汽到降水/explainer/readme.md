# 讲解：云和降水之间还隔着一个“粒子增长”

水汽、云和降水处在同一条天气过程链上，却不是同一个对象：

- 水汽是气态水，常常只能通过湿度、露点等变量间接描述；
- 云由悬浮的小水滴和/或冰晶组成；
- 降水强调粒子正在下落并可能到达地面。

因此，记录到“相对湿度高”时，最多可以说空气更接近饱和；记录到“有云”时，也只能说存在悬浮粒子。要形成地面降水，云中粒子还要继续增长，并在下落途中没有完全蒸发。

题目中的 14:00—17:00 只是一个适合练习的时间序列。它可以引导我们提出“水汽和上升冷却是否促成了云发展”的假设，但不能单凭三行数据确定因果关系。真实分析还要结合站点时间序列、探空、雷达、卫星或附近站点资料，并确认它们的时间和空间范围是否一致。

“空中有降水、地面没有雨”是很好的边界案例。雨幡说明从云中落下的粒子，在到达地面前可能因为周围空气较干而蒸发；这正好提醒我们，云、降水回波和地面降水观测不是完全等价的信号。
