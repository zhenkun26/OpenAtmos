# 参考解答：从水汽到降水

1. **水汽状态**可以由相对湿度这一列间接描述；**云**对应“云的观察”一列；**降水**对应“地面降水”一列。云的观察和雨量计记录是观察/仪器记录，相对湿度是仪器测量值；“上升、冷却、饱和、粒子增长”则是对过程的解释，不在表格中被直接观测到。

2. 一个合适的回答是：14:00 到 17:00 期间，空气中可能仍有较多水汽；若局地上升运动增强，空气上升冷却并更接近饱和，云中小水滴或冰晶可能继续增长，因而出现了阵雨。这个解释与记录相容，但单凭三行数据不能证明每一个环节，更不能排除平流、辐合或附近天气系统等其他因素。

3. 可能原因包括：

   - 相对湿度高只说明空气接近饱和，不代表已经形成足够大的降水粒子；
   - 云中粒子仍然很小，或云层中的上升运动和粒子增长过程不足；
   - 也可能有降水粒子在下落途中蒸发，没有到达地面。

   写出其中两个即可。注意：相对湿度 88% 也不能直接等同于“有 88% 的水”。

4. 可能是雨幡：降水粒子在较干的空气中下落并蒸发，形成空中的降水条带，但没有到达地面雨量计。还应检查雷达观测高度、观测时间和雨量计位置，不能只凭一个画面下结论。

5. 第一条是**观察事实**，因为它给出了雨量计在明确时间内的记录。第二条是**机制推断**，其中“上升运动增强”“粒子长大”和“因此”都需要更多观测或资料支持。

本练习的关键不是把每次降水都还原成完整微物理过程，而是养成顺序：先分开水汽、云和降水，再区分记录与解释，最后说明还需要什么证据。
