# 参考解答：把天气变成观测记录

1. 气象要素包括气温、相对湿度、平均风和降水；时间、来源以及题目中给出的地点属于观测记录的元信息。它们不是“大气状态量”，但决定了数据能否被理解和复核。
2. 示例：第三天 14:00，某校园气象点气温 28.7 °C、相对湿度 82%、平均风为东北偏东 1.6 m/s、降水量 6.4 mm；来源为练习用自动站。答案可以换一种顺序，但字段不能缺失。
3. 这是基于记录的推断。“更容易下雨”涉及概率或机制，表格直接记录的只是第三天出现了 6.4 mm 降水、湿度为 82% 等事实。
4. 优先寻找探空或其他能够提供垂直剖面的观测资料。地面站主要告诉我们近地面某点的状态。
5. 这道题没有唯一答案。关键是固定观测时间和地点，写清数据来自仪器、公开站点、人工目测还是其他来源，并注明缺测或异常情况。

本练习的重点不是算出一个天气结论，而是让每个结论都能追溯到“什么时间、什么地点、什么要素、什么来源”。
