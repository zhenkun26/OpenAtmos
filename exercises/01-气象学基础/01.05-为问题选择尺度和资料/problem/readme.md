# 练习：为问题选择尺度和资料

请先阅读第六课并观察 `time-space-scales.svg`。以下均为**合成教学情境**，不代表真实产品规格或某次南京天气过程。

| 情境 | 时间采样 | 空间信息 | 观测对象 |
| --- | --- | --- | --- |
| A | 每 1 分钟 | 一个校园自动站点 | 气温、风、降水 |
| B | 每 10 分钟 | 覆盖南京的网格图 | 雷达回波 |
| C | 每 3 小时 | 覆盖华东的较粗网格图 | 气压场和风场 |

1. A、B、C 哪一个时间分辨率最高？哪一个空间范围最大？为什么这两个答案不一定是同一个资料？
2. 如果问题是“校园未来 30 分钟会不会有阵雨”，你会把哪一份资料作为起点？还需要什么资料来避免把一个点的记录推广到整个校园？
3. 如果问题是“南京东部的雷暴单体怎样移动”，你会优先使用哪一类资料？为什么只看 A 不够？
4. 如果问题是“华东低压未来两天怎样演变”，为什么 C 比 A 更适合作为背景资料？它又可能看不清什么细节？
5. 请判断下面两句话分别主要讨论“时间尺度”“空间尺度”“时间分辨率”“空间分辨率”还是“代表性”：
   - “这个传感器每分钟记录一次。”
   - “这个雨量计的记录不能直接代表南京全市。”
6. 写一个你关心的气象问题，并补全：时间窗口是____，空间范围是____，我首先需要的资料是____。

完成后再打开 `solution/readme.md`，检查自己是否说明了“为什么”，而不是只填了一个资料字母。
