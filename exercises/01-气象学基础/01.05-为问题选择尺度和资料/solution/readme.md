# 参考解答：为问题选择尺度和资料

1. A 的时间采样最密，每 1 分钟一次；C 的空间范围最大，覆盖华东。A 的时间分辨率高，但空间上只是一个点；C 覆盖范围大，却每 3 小时更新一次、网格也较粗。时间分辨率和空间范围是不同维度。

2. 可以先看 A 的自动站/雨量记录，再结合 B 的雷达回波和附近站点。只看 A 不足以代表整个校园，因为站点所在位置的下垫面、建筑和局地降水分布可能与校园其他位置不同。

3. 优先使用 B 这类连续的区域雷达资料，并与多站点降水记录配合。A 只有一个点，能说明该站附近的变化，却很难判断雷暴单体的范围、移动方向和结构。

4. C 的覆盖范围和时间窗口更适合观察华东范围内、持续数天的天气背景；它可能看不清校园阵雨、雷暴核心和街区之间的降水差异。需要把它和更高时空分辨率的资料结合起来。

5. “这个传感器每分钟记录一次”主要讨论**时间分辨率**；“这个雨量计的记录不能直接代表南京全市”主要讨论**代表性**。前者不是时间尺度，后者也不是空间分辨率本身。

6. 示例答案：时间窗口是“今天 16:00—18:00”，空间范围是“学校周边 5 km”，我首先需要的资料是“附近自动站、雨量计和连续雷达回波”。只要时间、范围和资料相互匹配，答案可以不同。

本练习的关键不是给所有资料排一个永久名次，而是先明确问题的时间窗口和空间范围，再判断资料的采样、覆盖和代表性是否够用。
