# 讲解：资料的分辨率、覆盖范围和代表性不是一回事

A、B、C 三种合成资料故意把不同维度拆开：A 的时间采样最密，但只在一个站点；B 把变化展开到区域网格；C 覆盖更大的范围，却牺牲了时间和空间细节。

判断资料是否合适时，可以按下面的顺序检查：

1. **时间窗口**：问题关心的是分钟、小时、一天还是数天？
2. **空间范围**：问题关心的是一个传感器附近、一个城市还是一个天气系统？
3. **分辨率与覆盖**：资料的更新间隔、站点/网格间距和覆盖范围够不够？
4. **代表性和误差**：观测点的环境是否能代表目标区域？雷达回波、云图或模式场是否需要地面观测确认？

“每分钟记录一次”是时间分辨率的描述；“这条记录能不能代表全市”是代表性问题；“图上网格相隔多远”才更接近空间分辨率。把它们混成一个“精细程度”，就容易对资料作出过度判断。

真实天气往往是多尺度的：一个局地雷暴可以嵌套在区域低压或锋面背景中。因而最稳妥的做法通常不是只选一份资料，而是让点状观测、区域资料和大尺度背景互相校验，并把时间戳对齐。
