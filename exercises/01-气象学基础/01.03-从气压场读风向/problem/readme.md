# 练习：从气压场读风向

请先阅读第四课并观察 `pressure-wind-map.svg`。本练习采用“北半球、近地面、简化天气图”的限定；它训练读图思路，不要求计算真实风速。

1. 图中的 H 和 L 分别表示什么？判断依据是什么？
2. 压力梯度力在入门模型中从哪里指向哪里？
3. 区域甲在 400 km 内变化 8 hPa，区域乙在 80 km 内变化 8 hPa。哪一处压力梯度通常更强？为什么？
4. “北风”表示空气从哪里来、主要向哪里运动？
5. 为什么真实近地面风不能直接画成从高压中心直线指向低压中心？至少写出两个影响因素。
6. 如果你要验证一张简化图的判断，下一步应该查找哪一类观测资料？

完成后再打开 `solution/readme.md`，重点检查自己是否区分了“压力梯度力方向”和“实际风向”。
