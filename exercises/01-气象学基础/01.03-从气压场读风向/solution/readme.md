# 参考解答：从气压场读风向

1. H 是高压中心，中心附近等压线数值向内增大；L 是低压中心，中心附近等压线数值向内减小。
2. 在只考虑压力梯度力的入门模型中，从高压指向低压，作用是减小空间气压差。
3. 区域乙更强。同样 8 hPa 的变化压缩在更短距离内，单位距离的气压变化更快，压力梯度通常更强。
4. 北风从北方来，空气主要向南方运动。风向名称按“来向”记录。
5. 真实风还受到地球自转造成的地转偏向、地面摩擦、地形和天气系统结构等因素影响；至少写出其中两个即可。
6. 可以查找同一时间附近的地面站风向/风速和气压观测，必要时再结合天气图或更高空的探空资料。模型图和观测不一致时，要先检查时间、空间范围和资料类型。

本练习的关键不是记住一条箭头，而是形成顺序：先看压力分布，再看梯度，再区分简化受力和实际风场。
